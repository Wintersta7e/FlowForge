# scripts
- `check-trx.sh <results-dir> [--require-prefix <class-prefix>]` — fails unless exactly one TRX exists, at least one test ran and every test passed; the gate and both CI test jobs call it.
- `gate.sh [--filter <expression>]` — the local gate: restore with CI's pinned audit flags, Release build, tests with the TRX counter check (a full run also fails unless a `FlowForge.Tests.Visual.` test executed), frame check (a full run fails unless the PNGs written to `TestResults/visual/` match the ids in its `expected-frames.txt` manifest), format check; prints `GATE PASS … frames=<n> dir=<path>` or fails closed. A filtered run skips the visual-test requirement and the frame comparison, prints `frames=<found>` and `PARTIAL …`, and never satisfies a commit's gate.
