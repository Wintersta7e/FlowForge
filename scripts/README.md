# scripts
- `check-frames.sh <frame-dir>` — fails unless the folder holds an `expected-frames.txt` manifest listing at least one frame id and exactly one PNG per listed id, with no PNG left over; prints `frames=<found>/<expected>`; the gate and both CI test jobs call it on `TestResults/visual`.
- `check-trx.sh <results-dir> [--require-prefix <class-prefix>]` — fails unless exactly one TRX exists, at least one test ran and every test passed; the gate and both CI test jobs call it.
- `gate.sh [--filter <expression>]` — the local gate: restore with CI's pinned audit flags, Release build, tests with the TRX counter check (a full run also fails unless a `FlowForge.Tests.Visual.` test executed), frame check (a full run runs `check-frames.sh` on the PNGs written to `TestResults/visual/`), format check; prints `GATE PASS … frames=<n> dir=<path>` or fails closed. A filtered run skips the visual-test requirement and the frame comparison, prints `frames=<found>` and `PARTIAL …`, and never satisfies a commit's gate.
